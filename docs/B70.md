# Strata on the Intel Arc Pro B70: the `b70` branch

This branch is upstream Strata (`main` at 7dd5cf1) plus the work that targets the Arc Pro B70 (Battlemage, `bmg-g31`, 32 GB)
on Linux with the `xe` driver. Everything below was measured on one B70 in a Ryzen 9 5950X box (64 GB RAM, PCIe
host-to-device probe 12.3 GB/s) on 2026-10-24. Nothing here is a claim from another machine.

Removed from the fork because they did nothing or made things worse:
- `MADV_HUGEPAGE` on the expert mirror. On xe `sycl::malloc_host` is a PFN/IO mapping of `/dev/dri/renderD128`. The advice returns 0, but transparent hugepages never apply (AnonHugePages stays 0 kB, pages stay 4 kB).

## Speed against upstream

Setup:
- Model: Qwen3.8-Flash-Next GSQ-RCO IQ2_XS (ISTA-DASLab rev `ed59f92`), MTP draft, `--spec 4`, int8 KV, 32K resident KV.
- Memory: `--vram-reserve-mib 7168` (peak VRAM about 25 GB, because the card also drives the desktop), `STRATA_MIRROR_MIB=17000`.
- Each start: the page cache of every model file is dropped before the engine starts.
- Arms run in the order A B B A C C.
- Test: the `standard-v1` suite (`strata bench run`).

Medians in tokens/s:

| Arm | Prompt 4K | Prompt 16K | Decode short | Decode 4K | Decode 16K | Sanity |
| --- | ---: | ---: | ---: | ---: | ---: | :---: |
| A: upstream `main` + the one-line BMI2 build fix (it does not build without it) | 1,395 / 1,431 | 1,444 / 1,458 | 57.6 / 57.8 | 53.1 / 55.3 | 48.3 / 48.1 | 12/12, 12/12 |
| C: this branch without the community PRs | 1,494 / 1,497 | 1,500 / 1,500 | 57.0 / 57.0 | 54.0 / 50.4 | 51.8 / 52.7 | 12/12, 12/12 |
| B: this branch | 1,542 / 1,612 | 1,689 / 1,701 | 57.4 / 57.7 | 51.2 / 51.5 | 51.9 / 51.9 | 12/12, 12/12 |

- Prompt: +12% at 4K and +17% at 16K. The fork's own work accounts for +3-6%; the community PRs add the rest.
- Decode at 16K: maybe +8%. The run medians don't overlap, but each is only 3 sampled answers and the per-request ranges overlap fully; treat it as unconfirmed.
- Short and 4K decode: no difference beyond noise.
- Greedy (temperature 0) answers were byte-identical in all six runs.

The numbers are for this branch, not for the fork's `main` as it was before this review. They are lower than community numbers on bigger hosts because of the 7 GB VRAM reserve and IQ2_XS. Compare the arms with each other, not with other machines.

## Upstream 0.1.54 (2026-10-30)

Upstream `main` 870aedd9 (engine 0.1.54) is merged, and its CUDA engine changes since the port's last re-migration
(0.1.40.1) are re-migrated into `sycl/` (commit 8adf90cc lists what came in and what stays off).
The port's kernels and B70 defaults stay; NVIDIA/AMD-only paths stay out.

Measured on the same box, nothing else running: Flash-Next IQ2_XS, a 118,196-token prompt (repo docs with a needle),
a ~850-token answer, temperature 0, `--spec 4`, int8 KV, 32K resident, reserve 7168 MiB, mirror 17,000 MiB,
`STRATA_PLE_AUTO_RAM=0`. Order: old 8192, new, old 16384, new, old 8192.

| Arm | Prompt tok/s | Decode tok/s | Needle |
| --- | ---: | ---: | :---: |
| `b70` before the merge, `--prefill 8192` (what setup wrote for 128K) | 1,761 / 1,762 | 60.8 / 60.8 | yes / yes |
| `b70` before the merge, `--prefill 16384` | 1,861 | 58.5 | yes |
| this branch, `--prefill 16384`, the B70 defaults below | 1,852 / 1,855 | 64.3 / 64.4 | yes / yes |

- Against the old branch as setup configured it: prompt +5%, decode +6%. The prompt gain is the 16K chunk (the old
  engine reads as fast with it); the decode gain is the engine (+10% against the old one at the same chunk).
- B70 defaults (`apply_b70_defaults`; a variable you set wins, `STRATA_B70_DEFAULTS=0` skips all):
  `STRATA_SELECT_LONG=1`, `STRATA_SPEC_COST=1`, `STRATA_PREFILL_AUTO_MAX=16384`, and the port's own decode kernels that
  were measured but left opt-in: `STRATA_IQ_DECODE_FAST=1` (bitwise), `STRATA_MMVQ_KREG=1`, `STRATA_HC_Q8=1` (both change
  the summation order; the answers stay equivalent, not byte-identical). Setup writes `--prefill 16384` for a Battlemage
  card with 24 GB or more above 32K context (GPU timeline of the 118K prompt: 78.6 s at 4,096, 74.6 s at 8,192, 68.5 s
  at 16,384, 66.7 s at 32,768, which borrows twice the cache).
- Fixed: a prompt whose last chunk is short (under 1,024 tokens: the routed-only expert walk) stalled for good in 2 of
  3 runs on an 8K prompt - the stager's claimed runs of 8 blobs held an early job back until a late job's buffer was
  free, and that buffer was freed by a DMA the launching thread queues after it needs the early job. Runs are released
  piece by piece now (4 of 4 clean).
- `use_root_sync` (dpct's cooperative launch: every work-group resident at once; none of these kernels has a grid
  barrier) came back with the re-migration on 41 launches the fork had stripped; stripped again.
- `STRATA_HC_Q8`: the BF16 copies of the hyper-connection projections stay (upstream drops them; the port's prompt-path
  view of the dropped rows made the 118K prompt's logits NaN).
- Parity tests: 62 of 63 pass on the B70 (`ple_parity` needs model files, as before).
- Opt-ins checked on the B70: `STRATA_PREFILL_LAYER_MAJOR=1` runs (118K, needle found) but reads the prompt slower here
  (1,447 tok/s: its experts take the FP16 path, not the int8 ESIMD kernels). `STRATA_PLE_COMPACT=1` works only with
  `--ple-io mmap` (the default direct I/O does not map the table; a line says so). `STRATA_GR_FUSED=1`: no gain.
  `STRATA_DEQUANT_SIDE=1` is refused: it stalls at a different layer each run under the Level Zero v2 adapter (it runs
  under v1 and with `STRATA_PREFILL_SYNC=1`), and the card's one compute engine leaves it nothing to overlap.
- Switching conversations after a long one now costs ~2-3 s once: upstream parks the decoded conversation before the
  next one overwrites it (#2526), so going back to it later does not read its prompt again.
- Not tested: two cards (the default two-B70 pipeline now runs upstream's N-stage loop), `--parallel` / batch serving,
  sampled-temperature speed with `STRATA_SPEC_COST`.

## Build and run

    docker build --pull -t strata-sycl-dev sycl/tools
    docker run --rm -u $(id -u):$(id -g) -v "$PWD/..:/work" -e AOT=bmg-g31 -e REPO=/work/Strata \
        -e BUILD_DIR=/work/Strata/build-sycl-aot strata-sycl-dev "cd /work/Strata && bash sycl/tools/build.sh strata"

Serving works as in `docs/INTEL.md`.

On a 64 GB desktop:
- Leave `--ple-io` at its default (`direct`); `ram` locks the 28.8 GB PLE table.
- Set `STRATA_PLE_AUTO_RAM=0` (engine 0.1.54+): the PLE residency policy locks that same table in RAM whenever table +
  expert mirror + 8 GiB are free at load, and apps opened afterwards then run the desktop out of memory.
- Size `STRATA_MIRROR_MIB` so at least 7 GB stays free.
